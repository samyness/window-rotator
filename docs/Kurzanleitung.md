# Window Rotator – Kurzanleitung

Der Window Rotator zeigt mehrere geöffnete Programme (z. B. Edge-Dashboard und iVMS-4200-Kamerabild) abwechselnd auf dem Produktionsmonitor an.

## Einrichten in 5 Schritten

1. **Programme öffnen**, die angezeigt werden sollen (Edge mit Dashboard, iVMS-4200 mit Live-Ansicht).
   Tipp: Fenster vorher maximieren bzw. Edge mit **F11** in den Vollbildmodus schalten.
2. **Window Rotator starten.** Links erscheinen alle geöffneten Fenster. Fehlt eines: **Aktualisieren** (F5).
3. **Fenster hinzufügen:** Fenster von links nach rechts in die **Rotation** ziehen – oder doppelklicken bzw. **+** klicken.
   Die Reihenfolge ändern Sie per Ziehen oder mit den Pfeilen ▲ ▼.
4. **Anzeigedauer** je Fenster in Sekunden eintragen (3–3600). Rechts oben sehen Sie die gesamte Zyklusdauer.
   Mit dem Schalter lässt sich ein Eintrag vorübergehend deaktivieren, ohne ihn zu löschen.
5. **Start** drücken. Danach das Fenster einfach schließen – die Rotation läuft im Infobereich (neben der Uhr) weiter.

Änderungen werden automatisch im aktuellen Profil gespeichert.

## Bedienung im Infobereich

Symbol: rotes Quadrat mit Pfeil neben der Uhr (ggf. unter „˄“ ausgeblendete Symbole).

| Aktion | So geht's |
|---|---|
| Steuerung öffnen | Doppelklick auf das Symbol |
| Pausieren / Fortsetzen / Starten | Rechtsklick → „Rotation pausieren / fortsetzen / starten“ |
| Sofort weiterschalten | Rechtsklick → „Nächstes Fenster“ |
| Rotation anhalten (Programm bleibt aktiv) | Rechtsklick → „Rotation beenden“ |
| Programm ganz beenden | Rechtsklick → „Programm schließen“ |

„Rotation beenden“ und „Programm schließen“ sind absichtlich getrennt.

## Statusanzeige

Unten im Fenster: grüner Punkt = läuft, oranger Punkt = pausiert, grau = gestoppt; daneben das aktuelle Fenster und der Countdown bis zum nächsten Wechsel.
In der Rotationsliste ist das gerade angezeigte Fenster rot markiert; dort steht auch, wenn ein Fenster fehlt oder nicht aktiviert werden konnte.

## Häufige Fragen

**Ein Eintrag zeigt „Fenster nicht gefunden“.** Das Programm ist geschlossen. Programm wieder öffnen – der Eintrag wird beim nächsten Durchlauf automatisch zugeordnet. Bis dahin wird er übersprungen.

**Ein Eintrag zeigt „Mehrdeutig“.** Das Programm hat mehrere passende Fenster (z. B. mehrere Edge-Fenster). Eintrag anklicken und unten einen **Titelfilter** eintragen (z. B. „Dashboard“) – oder links das richtige Fenster markieren und **Markiertes Fenster zuordnen** klicken.

**Ich möchte während der Rotation etwas einstellen.** Vorher **Pause** drücken, sonst wechselt die Anzeige weiter.
