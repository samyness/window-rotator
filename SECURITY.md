# Security Policy

Window Rotator runs as a normal user process (`asInvoker`), needs no admin rights, opens no network connections and stores data only in the user's profile.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/samyness/window-rotator/security/advisories/new) instead. You'll get an answer within a few days.

## Supported versions

Only the latest release receives fixes.
